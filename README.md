# ⚡ AI PM Smart Sheet | نظام الشيت الذكي لإدارة المشاريع والجدولة اليومية

نظام متطور ومصمم خصيصاً لمدراء المشاريع الهندسية (Project Managers & Planning Engineers) وفق معايير معهد إدارة المشاريع العالمي (PMI/PMP). يتيح النظام لمدير المشروع رفع أي ملف متعلق بالمشروع (ملف Kick-off، كراسة شروط، جداول، خطة تعافي، سجلات اعتماد المواد MTS ومصفوفة المشتريات)، ليقوم الذكاء الاصطناعي بدراسة المشروع بالكامل وتحليله وتوليد **جدول مهام يومي تفصيلي** يغطي كل يوم حتى تاريخ التسليم النهائي (Handover).

---

## 🌟 المميزات الرئيسية:
1. **دراسة المستندات بالذكاء الاصطناعي (AI Document Analysis)**:
   - تحليل ملفات PDF, Word, Excel, وعروض الـ PowerPoint التقديمية.
   - استخراج نطاق الأعمال (Scope of Work)، المعالم الرئيسية (Milestones)، سجلات الاعتمادات (MTS)، وأوامر الشراء (POs).

2. **الجدولة اليومية الدقيقة (Day-by-Day Task Scheduler)**:
   - تقسيم أنشطة المشروع عبر مراحله الخمس: التهيئة (Mobilization)، الهندسة والاعتمادات (Engineering)، المشتريات والتوريد (Procurement & POs)، التنفيذ والتركيب الموقعي (Site Construction)، الفحص والتشغيل (Testing & Commissioning)، والتسليم النهائي (Handover).
   - ربط كل مهمة بتاريخ محدد، مسؤول (Owner)، موقع/مبنى، أولوية (Critical/High/Med)، ومخرج مطلوب (Deliverable).

3. **شيت بيانات تفاعلي (Interactive Spreadsheet Grid)**:
   - تعديل مباشر لحالات المهام ونسب الإنجاز.
   - فلترة وبحث سريع بالمسؤول، المرحلة، أو الكلمات المفتاحية.

4. **تصدير شيت Excel احترافي (.xlsx)**:
   - تصدير ملف إكسل متعدد الصفحات (Multi-Tab Workbook) يحتوي على:
     - 📑 `Dashboard_الملخص`: ملخص المشروع ومؤشرات الأداء (KPIs).
     - 📑 `Daily_Schedule_الجدول_اليومي`: المهام اليومية الكاملة.
     - 📑 `Milestones_المعالم`: المعالم وخطة التعافي.
     - 📑 `MTS_Procurement_المشتريات`: متابعة المواد وفترات التوريد الطويلة (8-12 أسبوع).
     - 📑 `Action_Items_القرارات_المعلقة`: القرارات وبنود التنسيق مع المالك والمقاول.

5. **دعم Google Sheets المباشر (Google Apps Script)**:
   - كود جاهز في مجلد `google-sheets/` يمكن نسخه في Google Sheets ليعمل الذكاء الاصطناعي مباشرة داخل شيت جوجل السحابي.

---

## 🚀 طريقة التشغيل السريعة:

### 1. عبر المتصفح والواجهة المحلية:
1. اضغط نقراً مزدوجاً على الملف `start.bat` (أو شغل الأمر `node server.js`).
2. سيفتح المتصفح تلقائياً على الرابط: `http://localhost:3000`
3. يمكنك استعراض مشروع القدية المحمل مسبقاً، أو رفع أي ملف مشروع جديد، وتصدير شيت الإكسل بضغطة زر.

### 2. توليد ملف Excel فوراً عبر سطر الأوامر (CLI):
```bash
node scripts/generate_excel.js
```
سيتم حفظ الملف في المجلد: `sample_output/Motor_Sports_Hotel_Complex_Schedule.xlsx`

### 3. داخل Google Sheets:
1. افتح Google Sheets ثم اختر: **Extensions > Apps Script**.
2. انسخ محتوى الملف `google-sheets/GoogleAppsScript_PMSheet.js` والصقه هناك ثم احفظ.
3. ستظهر لك قائمة جديدة باسم **"🤖 الذكاء الاصطناعي للمشاريع"** تمكنك من توليد الشيت اليومي بالكامل داخل حسابك.
